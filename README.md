# TRP Offline Charlist

Автономное Android-приложение для хранения и управления листами персонажей настольных ролевых игр (TTRPG). Позволяет вести учет характеристик, инвентаря и предыстории персонажей без необходимости подключения к интернету, гарантируя полный контроль над приватностью данных.

##  Стек технологий

- **Язык**: Kotlin 2.0.21
- **UI-фреймворк**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM (ViewModel + StateFlow)
- **Навигация**: Jetpack Navigation Compose
- **Хранение данных**: 
  - Jetpack DataStore (Preferences) для пользовательских настроек
  - `kotlinx.serialization` (JSON) для сериализации и локального сохранения листов персонажей
- **Сборка**: Gradle (Kotlin DSL), Java 11

##  Ключевые особенности

-  **Современный декларативный UI**: Интерфейс, полностью построенный на Jetpack Compose.
-  **Полный оффлайн**: Никаких сетевых разрешений и внешних зависимостей. Все данные остаются на устройстве.
-  **Чистая архитектура**: Разделение ответственности между слоями UI, ViewModel и Data.
-  **Актуальные стандарты**: Target SDK 36, оптимизированная работа с состояниями и жизненным циклом.

##  Требования для сборки

- Android Studio Ladybug (или новее)
- JDK 11 или выше
- Android SDK 36 (Compile SDK), Min SDK 24 (Android 7.0)
